# 대화 기반 MBTI 자기이해 리포트 (카톡·지피티 대화 텍스트 분석)

카카오톡·ChatGPT 등 **나의 대화 텍스트**를 붙여넣으면, 개인정보를 자동 마스킹한 뒤
대화 패턴에 근거한 MBTI 4축 성향 리포트를 만들어 주는 **클라이언트 전용 웹앱**입니다.

## 특징

- 🔒 **완전 클라이언트 처리** — 서버가 없습니다. 대화 텍스트는 브라우저 밖으로 전송·저장되지 않고, 탭을 닫으면 사라집니다.
- 🙈 **개인정보 자동 마스킹** — 화자 이름(나=화자A, 상대=화자B…), 전화번호, 계좌번호, 이메일, 본문 속 호칭(○○님 등)을 분석 전에 치환.
- 📊 **근거 인용 리포트** — 4축(E/I·S/N·T/F·J/P) 판정마다 마스킹된 원문 문장을 인용하고, 근거가 부족한 축은 "판단 보류"로 표시합니다. 근거 충분도도 함께 표시합니다.
- 📈 **정량 지표** — 발화 수·평균 길이·대화 개시율·응답 지연·웃음/이모지 밀도.
- 🖼️ **공유카드** — 결과를 PNG 이미지로 저장.
- 📄 **파일 업로드** — 카톡 PC 내보내기 `.txt` 파일 또는 지피티 대화 복사 텍스트 지원.
- 🔮 **v2 예정** — 만세력 명식 계산(사주 8자·오행·십성) + TCI식 미니 자기보고를 더한 3소스 융합 리포트.

## 사용 방법

1. 페이지를 엽니다 (설치·로그인 불필요).
2. 카톡 대화: PC 카카오톡에서 대화방 → 대화 내보내기 → 텍스트로 저장 → `.txt` 파일을 올리거나 텍스트를 붙여넣습니다.
3. 지피티 대화: ChatGPT 대화를 복사해 붙여넣습니다 (`사용자:`, `ChatGPT:` 형식).
4. **분석 대상 화자(본인)를 선택**합니다 — 셀프 분석은 본인 발화만 근거로 삼습니다.
5. "리포트 생성 및 분석"을 누르면 결과가 나옵니다. "📄 샘플 대화 불러오기"로 바로 체험할 수 있습니다.

## 주의

- 본 리포트는 **의료·임상적 진단이 아닌** 대화 패턴 기반의 자기이해 보조 콘텐츠입니다.
- MBTI·성향 판정은 통계적 검증을 거친 심리검사가 아니라 규칙 기반 휴리스틱입니다.
- 샘플 데이터는 모두 합성된 가상의 데이터입니다.
- 마스킹은 정규식 기반의 최선 탐지이며, 공유 전에는 결과를 직접 확인해 주세요.

## 기술

- 서버리스 단일 HTML(HTML·CSS·Vanilla JS), 외부 스크립트·API 호출 없음
- 회귀 테스트: `node tests/run_tests.mjs` (node 내장만 사용)
- 자세한 개발·검증 이력은 내부 문서 참고
