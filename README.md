# 카카오톡 대화 기반 MBTI 자기이해 리포트 (v1 프로토타입)

카카오톡 대화 내보내기 텍스트를 웹 브라우저에 붙여넣으면, 외부 서버로 대화를 전송하지 않고 브라우저 내부에서 실시간으로 개인정보(화자명·전화번호·계좌번호·이메일)를 마스킹한 뒤, 정량 지표와 마스킹된 원문 근거 인용을 결합하여 4축(E/I, S/N, T/F, J/P) 성향 분석 리포트 및 PNG 공유 카드를 생성하는 무서버(Serverless) 클라이언트 전용 웹 애플리케이션입니다.

---

## 1. 주요 기능

1. **무서버 완전 클라이언트 전용 처리 (Zero-Server Architecture)**
   - 대화 원문 데이터가 외부 API나 서버로 **비전송**되며, 사용자의 브라우저 메모리 안에서만 파싱 및 분석 후 즉시 소멸합니다.
2. **PII (개인식별정보) 자동 마스킹**
   - **화자명**: 사용자가 본인 화자를 선택하면 `나(화자A)`로 치환되고, 상대방은 `화자B`, `화자C` 등으로 익명화.
   - **전화번호**: `010-XXXX-XXXX`, 일반 유선전화 정규식 검출 후 `[전화번호 마스킹]` 치환.
   - **계좌번호**: 주요 은행명 및 11~14자리 계좌 번호 패턴 검출 후 `[계좌번호 마스킹]` 치환.
   - **이메일**: 이메일 주소 패턴 검출 후 `[이메일 마스킹]` 치환.
3. **정량 커뮤니케이션 지표 산출**
   - 발화 메시지 수, 평균 발화 글자 수, 대화 개시율(%), 평균 응답 지연 시간(분), 웃음(ㅋ/ㅎ) 밀도, 이모지/기호 밀도.
4. **한국어 어휘 사전 & 휴리스틱 기반 4축 MBTI 분석**
   - E/I (외향/내향), S/N (감각/직관), T/F (사고/감정), J/P (판단/인식) 4개 축별 뉘앙스 분석.
   - 대화량 및 증거가 부족할 경우 축별 및 전체 결과에 **'근거 부족'** 경고 및 신뢰도(%) 명시.
   - 각 축 판정에 결정적으로 기여한 마스킹된 실제 대화 문장을 발췌 인용하는 **원문 근거 카드** 제공.
5. **HTML5 Canvas 기반 요약 공유카드 & PNG 다운로드**
   - 브라우저 Canvas API를 통해 고해상도 요약 카드를 실시간 렌더링하고, `toDataURL`을 활용해 클릭 한 번으로 PNG 이미지 다운로드.

## 2. 프라이버시 및 비진단 원칙

- **비전송·비보존 원칙**: 모든 텍스트 데이터는 사용자의 로컬 브라우저 탭을 벗어나지 않습니다. 서버 로그, 데이터베이스 저장, 외부 추적기가 전혀 없습니다.
- **자기이해 목적 고지**: 본 서비스의 리포트는 정신의학적·임상적 심리 평가나 공식 MBTI 검사를 대체하지 않으며, 일상적인 대화 습관을 스스로 되돌아보고 관계를 조율하기 위한 **자기이해** 보조 도구입니다.

2. **파서 견고성 및 시간 역행 방어 (P2-4, P2-5)**
   - 다양한 날짜 구분선(`---` 다수 및 연/월/일 포함) 인식 확장.
   - 자정 통과 시 날짜선 미인식 또는 시간 역행이 발생하더라도 가상 일자 오프셋을 자동 감지해 세션 시작 및 응답 지연 시간이 오염되지 않도록 방어.
   - 콜론이 포함된 화자명(예: `팀장:철수`, `Dr:Kim`)도 마지막 콜론 기준으로 화자와 본문을 올바르게 분리.
3. **정량 지표 및 신뢰도 산식 정밀화 (P2-6, P2-7)**
   - 대화 상대가 없거나 회신 쌍이 없는 경우 개시율과 응답 지연을 왜곡된 E/J 가중치로 사용하지 않고 '근거 부족'으로 명시.
   - 축 내 격차(margin ratio)와 유효 근거 문장 수를 직접 반영하여 격차가 작거나 근거가 적을 경우 신뢰도를 낮게 산출(임의 상한 합산 제거).

## 3.6. 독립 검토 2라운드(Luna R2) 반영 및 신기능 탑재

독립 코드 검토 2라운드 findings 4건 수정과 신규 편의/수익화 기능을 적용하였습니다:

1. **textarea 입력 변경 시 전체 상태 즉시 초기화 (P1 수정)**
   - 텍스트 수정, 삭제, 붙여넣기 발생 시 `selectedSpeaker`, `parsedData`, 마스킹 미리보기, 분석 결과, 종합 섹션 잠금 상태를 즉시 초기화.
   - 화자 목록 드롭다운을 재계산하며, 이전 대화의 실명 및 분석 결과가 DOM 어떤 영역에도 잔류하지 않도록 보장.
2. **문맥 키워드 후속 날짜 패턴 계좌 오탐 방지 (P2 수정)**
   - `YYYY-MM-DD`, `YYYY.MM.DD`, `YYYY/MM/DD`, `YYYY년 M월 D일` 등 정규 날짜 형식은 문맥 키워드(입금, 송금 등) 바로 뒤에 등장하더라도 계좌번호로 오탐 마스킹하지 않고 온전히 보존.
3. **유효 교대(회신 쌍) 0건 시 근거 부족 처리 & 일방향 대화 회귀 방어 (P2 수정)**
   - 타 화자의 메시지가 뒤따르는 유효 회신 쌍(`partnerFollowCount`)이 0건인 경우(1인 독백 또는 '나→상대' 일방향 대화), 개시율 및 응답지연을 모두 '근거 부족'으로 표시하고 E/J 스코어 가중치에서 완전히 배제.
4. **메시지 헤더 분리 정밀화 (P2 수정)**
   - 타임스탬프 이후 첫 `' : '`(공백-콜론-공백)을 우선 분리자로 사용하고 없을 경우 마지막 콜론으로 폴백.
   - 본문 내 URL(`https://...`)이나 문장 속 콜론이 화자명 분리에 혼선을 주지 않도록 완벽 차단.
5. **신기능 1: 텍스트 파일 업로드 (.txt)**
   - `accept=".txt"` 파일 입력 및 `FileReader` API를 통해 로컬 파일을 textarea에 즉시 주입.
   - 1MB 초과 대용량 파일은 브라우저 메모리 보호를 위해 즉시 안내 메시지와 함께 업로드 거부.
6. **신기능 2: 500원 소액 페이월 ('MBTI+사주 종합 결과 보기')**
   - **무료 영역**: 현행 기본 MBTI 리포트 및 Canvas 요약 카드 전체.
   - **유료 영역 (500원)**: MBTI 4축 심층 해석 & 소통 전략 + 사주·TCI 융합 v2 예정 종합 안내.
   - **데모 모드 & 토큰 만료**: 토스페이먼츠 키 미주입 상태에서는 '데모 모드' 배지와 함께 원클릭 시뮬레이션 잠금 해제 지원. 잠금 해제 시 브라우저 `localStorage`에 24시간 만료 토큰을 저장하여 새로고침/재방문 시에도 권한 유지.

## 4. v2 차세대 확장 설계 노트 (사주 명식 & TCI 융합)

v1이 카카오톡 일상 언어 습관(텍스트 휴리스틱)에 집중했다면, v2에서는 보다 다각적이고 입체적인 인간 이해를 위해 **[대화 텍스트 휴리스틱 + 사주 명리학 + TCI 심리검사] 3소스 융합 아키텍처**로 진화합니다.

### 4.1 사주 명식(四柱 命式) 계산 모듈
- **사주 8자 산출**: 생년월일시 입력을 바탕으로 만세력 알고리즘을 통해 연주, 월주, 일주, 시주 천간·지지 도출.
- **오행 분포 분석**: 목(木), 화(火), 토(土), 금(金), 수(水)의 5대 기운 비율 및 과다/고립 상태 산출.
- **십성 명식 체계**: 일간(日干)을 기준으로 비견(比肩), 겁재(劫財), 식신(食神), 상관(傷官), 편재(偏財), 정재(正財), 편관(偏官), 정관(正官), 편인(偏印), 정인(正印)의 10대 관계성 패턴 도출.
- **검토 루브릭(Rubric) 재활용**: 기존 GPT 사주 기초검토에서 정립된 엄밀한 해석 가이드라인을 '검토 루브릭'으로 시스템화하여, 맹신적 운세 풀이를 지양하고 개인의 기질적 성향과 성찰 포인트로 변환.

### 4.2 TCI (기질 및 성격 검사) 12~20문항 미니 자기보고 모듈
- 유전적/생득적 영역인 **기질 4차원** (자극추구 NS, 위험회피 HA, 사회적보상의존 RD, 인내력 P)과 후천적/성숙 영역인 **성격 3차원** (자율성 SD, 연대감 CO, 자기초월 ST)을 경량화된 미니 서베이로 측정.
- 약 2~3분 내 응답 가능한 12~20문항 미니 척도로 사용자 부담 최소화.

### 4.3 3소스 교차 검증 및 융합 구조
```
[ 소스 1: 카카오톡 대화 ] ───> 실제 발화 습관, 관계 속 표출 패턴 (외현적 행동)
[ 소스 2: 사주 명식 8자 ] ───> 오행·십성 기운의 조화, 사주 검토 루브릭 (잠재적 기질)
[ 소스 3: TCI 자기보고 ]  ───> 기질적 자극 반응 & 성격적 성숙도 (내면적 자기인식)
                 │
                 ▼
      [ 3소스 입체 융합 엔진 ]
                 │
                 ▼
  통합 심층 자기이해 리포트 (인지-정서-행동 다차원 프로파일)
```
- **상호 보완성**: 대화 분석에서 '근거 부족' 판정이 발생하더라도 사주 및 TCI 데이터를 교차 검증하여 결측치를 보정하고, 표면적 소통 스타일과 내면 기질 간의 간극(예: 외향적 언어 사용 vs 높은 TCI 위험회피 성향)을 짚어주는 심층 인사이트를 제공합니다.

## 5. 결제 연동 가이드 (토스페이먼츠 500원 소액 페이월)

본 프로젝트는 최소한의 허들을 갖춘 **500원 소액 페이월 모델**을 채택하고 있으며, 실결제 오픈(Go-Live) 시 토스페이먼츠(Toss Payments)를 최우선 권장 PG사로 안내합니다.

### 5.1 토스페이먼츠 권장 근거
1. **개인 간이과세자/소규모 영업자 즉시 계약 가능**: 복잡한 법인 보증보험 없이도 사업자등록증(간이과세자 포함)만으로 빠른 비대면 온라인 계약 승인이 지원됩니다.
2. **초소액 결제(100원 이상) 지원**: 카드사 최소 승인 금액인 100원 이상의 결제를 안정적으로 지원하여 500원 마이크로 트랜잭션 구현에 최적화되어 있습니다.
3. **합리적인 가맹점 수수료**: 영세·중소 가맹점 우대 수수료율 기준 신용카드 약 2.5% ~ 3.5% 수준으로 결제 수수료 부담이 적습니다.
4. **무료 온보딩 및 개발자 친화성**: 가입비 및 연회비가 무료이며, 직관적인 JavaScript SDK와 웹훅/서버 승인 API 문서가 완비되어 있습니다.

### 5.2 실결제 오픈(Go-Live) 절차
1. **토스페이먼츠 개발자센터 가입 & 키 발급**:
   - 상점 관리자 가입 후 `클라이언트 키(Client Key)`와 `시크릿 키(Secret Key)`를 발급받습니다.
   - `index.html` 상단의 `TOSS_PAYMENTS_CLIENT_KEY` 상수에 발급받은 클라이언트 키를 주입합니다.
2. **클라이언트 SDK 동적 로딩 안내**:
   - 외부 네트워크 차단 및 CSP(콘텐츠 보안 정책) 준수를 위해 기본 코드에는 외부 스크립트 태그를 포함하지 않았습니다. 실서비스 배포 시점에 아래 스크립트를 동적으로 로드하거나 `<head>`에 포함합니다:
     ```html
     <script src="https://js.tosspayments.com/v1"></script>
     ```
3. **최소 백엔드 검증 서버(Cloudflare Workers 권장) 구축**:
   - 클라이언트에서 결제 요청 후 발급된 `paymentKey`, `orderId`, `amount`를 클라이언트가 신뢰할 수 있는 최소 서버로 전송합니다.
   - Cloudflare Workers(서버리스 무료 티어)에서 토스페이먼츠 결제 승인 API(`https://api.tosspayments.com/v1/payments/confirm`)를 Basic Auth(Secret Key 인코딩)로 호출하여 위변조 여부(`amount === 500`)를 최종 검증합니다.
   - 검증 성공 시 클라이언트에 24시간 유효 서명 토큰을 반환합니다.
4. **웹훅(Webhook) 처리 (선택)**:
   - 가상계좌 입금이나 결제 취소/환불 시 토스페이먼츠 웹훅을 Workers 엔드포인트로 수신하여 권한 토큰을 무효화합니다.

### 5.3 결제 솔루션 대안 비교
- **카카오페이 / 네이버페이 단독 계약**: 국내 사용자 결제 전환율은 매우 높으나, 개별 심사 절차와 별도 계약 및 정산 관리가 필요하여 초기 단독 연동으로는 리소스 부담이 있습니다.
- **PortOne (구 아임포트)**: 토스, 카카오, 네이버, 다날 등 다중 PG사를 통합 연동하기에 용이하나, 중계 수수료 및 별도 계정 관리가 동반됩니다. 단일 500원 결제에는 토스페이먼츠 직연동이 가장 가볍고 효율적입니다.

### 5.4 법적 및 세무적 유의사항
1. **간이과세자 및 통신판매업 신고**:
   - 결제 금액을 정산받기 위해 사업자등록(간이과세자 가능)이 필요합니다.
   - 전자상거래 등에서의 소비자보호에 관한 법률상 직전 연도 거래 횟수 50회 미만인 경우 통신판매업 신고가 면제될 수 있으나, 본격적인 유료 서비스 운영 시에는 관할 구청 통신판매업 신고 및 정부24 등록을 권장합니다.
2. **개인정보처리방침 PG 위탁 고지**:
   - 결제 처리를 위해 결제 정보가 PG사(토스페이먼츠)에 위탁됨을 서비스 하단 개인정보처리방침에 명시해야 합니다. (본 서비스는 대화 원문은 비전송 메모리 격리를 유지하며 오직 결제 정보만 PG로 위탁됨을 투명하게 안내)
3. **가격 표시 및 부가가치세(VAT)**:
   - 가격 표기 시 부가가치세가 포함된 금액(예: `500원 (부가세 포함)`)임을 명확히 표시하여야 합니다.
4. **에스크로(구매안전서비스) 의무 면제**:
   - 건당 5만원 미만의 소액 결제는 전자상거래법 시행령에 따라 결제대금예치(에스크로) 적용 의무가 면제되므로, 500원 리포트는 별도 에스크로 확인서 없이 즉시 판매 가능합니다.
